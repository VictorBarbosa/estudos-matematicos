A figura e seu retângulo

@if (usaInclinacao()) {

Mexa na inclinação do topo: a área não muda. O que conta é a altura — a distância entre as bases —, nunca o comprimento do lado inclinado. É o erro mais comum em paralelogramos.

} @else if (ehTrapezio()) {

Duas cópias deste trapézio, uma girada, formam um paralelogramo de base B + b. Daí a área ser a média das bases multiplicada pela altura.

} @else {

No retângulo a área é a própria definição: quantos quadrados de lado 1 cabem dentro. Todas as outras fórmulas voltam a esta por corte e recomposição.

}
