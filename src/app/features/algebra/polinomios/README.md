# Polinômios

Grau, divisão, teorema do resto e a busca das raízes.

**Área:** Álgebra · **Rota:** `/algebra/polinomios`

O tópico que abre a porta para graus acima de 2: achar uma raiz, dividir por `(x − raiz)`
e cair num grau menor até Bhaskara dar conta. A matemática vive em
`core/math/algebra/divisao-polinomial.ts`.
