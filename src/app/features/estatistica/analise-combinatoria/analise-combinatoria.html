A pergunta que decide tudo

A ordem importa? Se importa, pare no arranjo. Se não importa, cada grupo foi contado p! vezes — uma para cada ordem possível — e é preciso dividir. Não há terceira fórmula a decorar: os indicadores acima mostram que a combinação é só o arranjo dividido por p!.
