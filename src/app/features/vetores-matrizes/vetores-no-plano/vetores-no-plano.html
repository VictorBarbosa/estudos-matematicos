A soma como diagonal do paralelogramo

O vetor roxo é a soma. Note que ele é a diagonal do paralelogramo formado pelos outros dois — e que seu comprimento quase nunca é a soma dos comprimentos.

Por que o módulo da soma é menor

Gire o vetor a e acompanhe os dois últimos indicadores. Eles só coincidem quando a e b apontam exatamente para o mesmo lado. Em qualquer outra configuração, parte de um cancela parte do outro — é a desigualdade triangular aparecendo de novo.

Decomposição: de ângulo para componentes

Decompor é o truque que resolve metade dos problemas de física: em vez de lidar com um ângulo, lida-se com dois eixos independentes. Os tracejados no gráfico são justamente os catetos desse triângulo.
