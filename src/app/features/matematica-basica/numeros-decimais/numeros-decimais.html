Aproximações na reta

Cada casa decimal a mais aproxima o valor exato sem nunca alcançá-lo, quando a dízima é infinita.

De dízima para fração

A subtração faz as infinitas casas decimais se cancelarem — é esse cancelamento que transforma um número infinito numa equação de uma linha.
