# Notação científica e unidades

Ordens de grandeza, prefixos do SI, conversões e algarismos significativos.

**Área:** Matemática básica · **Rota:** `/matematica-basica/notacao-cientifica-unidades`

É o primeiro tópico com sabor de engenharia: um número não vale nada sem a unidade,
e não vale muito sem a precisão. A matemática vive em
`core/math/numeros/notacao-cientifica.ts`.
