# Progressões

PA e PG: termo geral, soma dos termos e onde cada padrão aparece.

**Área:** Funções · **Rota:** `/funcoes/progressoes`

A distinção que organiza o tópico: somar sempre a mesma coisa dá uma reta, multiplicar
sempre pela mesma coisa dá uma exponencial. A matemática está em
`core/math/calculo/sequencias.ts`, compartilhada com Pré-cálculo.
