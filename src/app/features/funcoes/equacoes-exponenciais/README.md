# Equações exponenciais e logarítmicas

Igualar as bases, tirar o logaritmo, trocar a potência por t e conferir o domínio.

**Área:** Funções · **Rota:** `/funcoes/equacoes-exponenciais`

## O que este módulo tem

- `equacoes-exponenciais.ts` / `.html` / `.scss` — Explorar com a curva y = bˣ e a reta y = c, e o
  cruzamento x = ln c / ln b; aba Treinar.
- `equacoes-exponenciais.gerador.ts` — seis perguntas: mesma base, com logaritmo, soma de logs (com
  raiz a descartar), substituição t = aˣ, tempo de crescimento e bases diferentes.
- `equacoes-exponenciais.teoria.ts` — quatro verbetes, cada um com exemplo resolvido.

## Por que existe

A avaliação de 09/11/2026 apontou a falta (`curriculo.ts` admitia): as aplicações de EDO tiram tempos de
logaritmos, e o site ensinava o logaritmo sem ensinar a resolver equações com ele.
