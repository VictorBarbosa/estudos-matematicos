# Circuitos

Lei de Ohm, potência, associação de resistores, Kirchhoff e o circuito RC.

**Área:** Eletricidade e magnetismo · **Rota:** `/eletromagnetismo/circuitos`

- `circuitos.ts` / `.html` / `.scss` — Explorar com o RC: R, C, fonte e tempo; a curva q(t) com τ marcado.
- `circuitos.gerador.ts` — Ohm, potência (V²/R e RI²), equivalente série/paralelo, divisor de tensão,
  circuito misto, malha com duas fontes, τ = RC, carga no tempo e duas malhas pela lei dos nós.
- `circuitos.teoria.ts` — cinco verbetes com exemplos resolvidos.
